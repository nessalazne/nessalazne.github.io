5 Claude Code Skills — Real Project Setup Guide

The 5-Skill Stack That Automates Your Entire Content Workflow
01

Skill 1: AI Series Script Writer

Install by dropping the skill file into your Claude Code project. Trigger it with /ai-series-script plus your topic and target audience. Claude outputs a complete hook → value → CTA script in your brand voice, plus platform-specific titles for YouTube Shorts, Reels, TikTok, and Pinterest — all in one run.

💡 Quick Tips
  • Input: topic + target audience + series name
  • Output: full script + 5 platform title variants
  • Run at the start of every content session
02

Skill 2: Freebie PDF Generator

Give the skill a topic, 3–5 key steps from the video, and the CTA keyword viewers will comment. It builds a branded PDF layout and outputs a print-ready file. Connect to ManyChat or another DM tool: when a viewer comments your keyword, the automation sends the PDF link. Every video becomes an email capture machine.

💡 Quick Tips
  • Input: video topic + key steps + CTA keyword
  • Output: branded PDF saved to assets/pdfs/
  • Pair with ManyChat for DM automation
03

Skill 3: SEO Blog Writer

The full publish flow runs inside one Claude Code session: write post → insert freebie CTA → generate header image via Kie.ai → copy to _posts/ → git push to GitHub Pages → update Airtable. Your video becomes a long-form SEO asset that drives organic traffic for months.

💡 Quick Tips
  • Input: video topic + YouTube link + CTA keyword
  • Output: published blog post at blog.digicuratoragency.com
  • Header image auto-generated — no Canva needed
04

Skill 4: Shorten Audio

Run this skill on your raw voiceover before editing. It uses ffmpeg to strip silences (silenceremove filter), applies a gentle 1.1× speed-up if needed, and hard-trims to 58 seconds as a last resort. Check output length with ffprobe -i output.mp3 -show_entries format=duration. Feed the cleaned file straight to your video editor.

💡 Quick Tips
  • Run before video editing — not after
  • Target: ≤58 seconds for Reels/Shorts compliance
  • Output: clean MP3 in the same folder as the input
05

Skill 5: Content Repurposer

Input your video script or blog post. The skill generates platform-native captions for Instagram, TikTok, Pinterest, YouTube, and LinkedIn — each with the right length, hashtags, and CTA format. Pass the outputs directly to Blotato MCP to schedule across all platforms in one command.

💡 Quick Tips
  • Input: script text or blog post path
  • Output: 5 platform-specific caption variants
  • Schedule via Blotato MCP — list accounts first
06

Putting It All Together

Run these 5 skills in sequence every time you publish: (1) Script Writer → creates your video script. (2) Shorten Audio → cleans the voiceover. (3) Freebie PDF → builds the lead magnet. (4) SEO Blog Writer → publishes the blog post with freebie CTA embedded. (5) Content Repurposer → generates social captions for every platform. Idea to fully published content in under one hour.

💡 Quick Tips
  • Skills run in one Claude Code session
  • Each output feeds the next skill in the chain
  • The system ships the content — you just review
