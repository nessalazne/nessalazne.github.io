## What Does the /mindmap Command Do in ChatGPT?

The /mindmap command makes ChatGPT build a mind map of the most important topics in whatever book you dropped into the chat. It works from the book itself, so the map follows the author's real structure and not a generic summary.

A mind map shows you how the big ideas connect, which makes every later read faster because you already know where each chapter fits.

## What Are the Four Commands and What Does Each One Make?

Each command takes the same book and returns a different format, so you pick the one that matches how you learn. Here is the full list from the video:

| Command | What ChatGPT builds | Best for |
|---|---|---|
| /mindmap | A mind map of the most important topics in the book | Seeing the big picture first |
| /sketchnotes | Handwritten-style summary notes | Quick review and skimming |
| /flashcards | Simple cards with the key points | Memorizing ideas fast |
| /educationalcomics | The main idea as a visual comic page | Visual learners |

You are not limited to one. Running /mindmap first and /flashcards second gives you the structure and the memory cards from a single book.

## How Do You Use the Commands Step by Step?

You only need a book, a ChatGPT chat and one slash command. Here is the order I would run them in:

1. Drop the book you want to read into ChatGPT.
2. Type /mindmap to see the main topics and how they connect.
3. Type /sketchnotes if you want a handwritten-style summary to review later.
4. Type /flashcards for the key points you need to remember.
5. Type /educationalcomics when you want the main idea as a visual page.
