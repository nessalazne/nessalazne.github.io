## Why Does AI-Generated Motion Graphics Look Like Slop?

AI motion graphics look like slop because the model reaches for whatever is most common in its training data, and that means the same tired defaults on every render. When you ask Claude Code to build a Remotion scene with no design rules, you get the visual clichés that flooded the internet in the first place.

The usual symptoms are easy to spot:

- Purple gradients on every background because gradients are the safe default
- Random zooms and pushes that move for no reason
- Fake screen demos that no real user would recognize
- Text and shapes animating in without pointing at anything important
- Wrong or generic logos when a brand mark should appear

None of this is a Remotion problem. Remotion is a React framework that renders real, frame-accurate video from code, so it can produce broadcast-quality work. The gap is direction. The skills below are the direction.

## How Do Purposeful Motion and Focus Work?

Purposeful motion means each animation earns its place by moving the story forward rather than filling time. When an element slides in, it should reveal a point; when the camera pushes, it should draw the eye toward the thing that matters next.

Here is the mental model the skills encode:

1. Decide what idea the shot has to land before you animate anything.
2. Give one element the job of carrying that idea.
3. Animate only what supports it, and hold everything else still.
4. Use a highlight, a scale, or a clean reveal to point at the key detail.

That last step is the focus highlight in action. A frame that emphasizes one thing reads instantly, while a frame where five things move at once reads as noise. ## FAQ

### What is Remotion?

Remotion is an open-source framework that lets you create videos and motion graphics using React code. You write components, and Remotion renders them into real, frame-accurate MP4 video.

### Do I need to know how to code to use these skills?

No. You describe the scene in plain language and Claude Code writes the Remotion components for you. The skills carry the design rules so you focus on the message, not the syntax.

### Why do AI motion graphics look generic by default?

Because the model defaults to the most common patterns in its training data, which means purple gradients, random zooms, and fake demos. Adding skills with clear design rules replaces those defaults with intentional choices.
