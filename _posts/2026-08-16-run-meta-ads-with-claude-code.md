## How Does Claude Code Run Meta Ads?

Claude Code runs Meta ads by connecting to the Meta Marketing API through your own API key, then taking control of the campaign build inside your ad account. Claude Code is Anthropic's AI coding agent that runs in your terminal, and the workflow leans on a public GitHub repo that packages the whole setup so you don't have to write the integration yourself.

The flow is short:

1. **Grab the GitHub repo** — a public repo holds the campaign scripts and the connection logic.
2. **Open Claude Code and paste the URL** — Claude Code reads the repo and understands the task.
3. **Connect your Meta API key** — the agent walks you through authenticating against your ad account.
4. **Hand it your product videos** — these become the raw material for the creatives.
5. **Let it take control** — Claude Code writes the copy, assembles the creatives, and structures the campaign.

Once it has access, the AI is doing the work a media buyer would normally do by hand: audience structure, ad copy, creative variations, and launch.

## Is It Safe to Give an AI Your Ad Account?

Giving an AI agent access to your ad account is a real decision, so treat it like hiring a new media buyer: start small and watch closely. A few guardrails keep the risk low:

- **Start with a small daily budget** — test with an amount you'd be fine losing, not your full monthly spend.
- **Use a dedicated API key** — you can revoke access instantly if anything looks off.
- **Review before scaling** — read the copy and check the creatives before pushing more budget.
- **Watch the first 48 hours** — early performance tells you whether to scale or pause.
