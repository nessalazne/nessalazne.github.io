## What Is a Claude Code Skill?

A skill is a markdown instruction file that tells Claude how to perform a specific, repeatable task. You drop it into your project and Claude follows it like a checklist — every time, consistently, in your brand voice.

Instead of rewriting the same prompt 40 times, you write it once, save it as a skill file, and call it on demand. Skills are the difference between Claude being a chat tool and Claude being an agent that runs your workflow.

Here are the 5 I use in a real content project.

## Skill 1: AI Series Script Writer

**What it does:** Generates a complete short-form video script — hook, value, CTA — for a specific content series, in your brand voice. It also outputs platform-specific titles for YouTube Shorts, Reels, TikTok, and Pinterest.

**How it works in a real project:**

Every video I make for the "AI Systems That Work" series starts here. I give the skill a topic and a target audience, and it returns a script in under 2 minutes — already formatted for my series structure. No blank page, no second-guessing the hook.

The platform titles mean I don't rewrite copy for six different channels. It's done with the script.

## Skill 2: Freebie PDF Generator

**What it does:** Creates a branded, print-ready PDF guide that pairs with a short-form video. Designed to drive email capture via DM automation — viewers comment a keyword, they get the PDF, they join your list.

**How it works in a real project:**

After every video, I generate a matching PDF freebie. The skill takes the video topic and key steps, builds the layout, and outputs a file I can attach to my DM flow. No Canva, no graphic designer, no waiting.

This alone runs a functioning email capture system from every piece of content I publish.

## Skill 3: SEO Blog Writer

**What it does:** Writes a full SEO-optimized blog post from a content brief, formats it as a Jekyll markdown file, generates a header image, and pushes it to GitHub Pages — automatically.

**How it works in a real project:**

Every video gets turned into a blog post within the same session. The skill writes the content, inserts the freebie CTA, generates the header image, commits everything, and pushes to my blog at `blog.digicuratoragency.com`.

The blog post then drives organic traffic for months after the video stops performing on social.

## Skill 4: Shorten Audio

**What it does:** Trims a voiceover recording to fit under 58 seconds — removes silences, applies a gentle speed-up if needed, and exports a clean MP3.

**How it works in a real project:**

My voiceovers always run 5–10 seconds long. Before I edit anything, I run this skill on the raw audio. It handles silence removal, subtle speed adjustments, and hard trim as a last resort. By the time the file lands in my video editor, it's already optimized — no manual trimming required.

## Skill 5: Content Repurposer

**What it does:** Takes one piece of content (a script, a blog post, or a video transcript) and generates platform-specific captions for Instagram, TikTok, Pinterest, YouTube, and LinkedIn — with format, hashtags, and CTAs tailored to each platform.

**How it works in a real project:**

Once a video is published, I run the repurposer. It reads the script and outputs caption variations for every platform. What used to take 2 hours now takes about 5 minutes. I review, schedule, and I'm done.

## How All 5 Fit Together in One Real Workflow

This is the actual sequence I run every time I publish a piece of content:

1. **AI Script Writer** — generates the video script and platform titles
2. **Shorten Audio** — cleans the voiceover before editing
3. **Freebie PDF** — creates the email-capture lead magnet
4. **SEO Blog Writer** — writes, images, and publishes the blog post (with freebie CTA embedded)
5. **Content Repurposer** — generates social captions for every platform

From idea to published content across blog + social takes under an hour. That's the entire point of building a skill stack — the system does the work, not you.
